# Midterm feedback survey (SOCIOL 723, Fall 2026)

Four anonymous open-ended questions: what is working, what is not, one thing
to keep, one thing to revise.

1. In Duke Qualtrics (duke.qualtrics.com): **Create a new project → Survey →
   Import a QSF file**, choose `midterm_feedback.qsf`, then **Publish**.
   The survey is already set to anonymize responses (no IP or contact data).
2. Under **Distributions → Anonymous link**, copy the link
   (`https://duke.qualtrics.com/jfe/form/SV_...`).
3. In this folder run
   `Rscript make_qr.R "<that link>"`
   to get `qr_code.png` and `qr_code.pdf`.
